# Numbat

Architectural productivity tools for Rhino 8.

Numbat is a growing collection of lightweight modelling and analysis tools designed to speed up common architectural workflows in Rhino.

## Installation

1. Open **Rhino Package Manager**
2. Enable **Include pre-releases**
3. Search for **Numbat**
4. Install

## Commands

### nbRandomColour

Randomises the colours of file layers.

### nbGFA

Calculates Gross Floor Area (GFA) from selected closed polysurfaces by measuring the area of each volume's bottom face.

### nbTextureShuffle

Randomly shuffles texture mapping across selected objects to introduce variation in rendered materials.

### nbPavementPlacer

Automatically arrays a paving module along one or more selected curves, with options for multiple rows, gaps, rotation and scale variation.

### nbHandrail

Generates configurable architectural handrails from selected curves.
