# Numbat

Architectural productivity tools for Rhino 8.

Numbat is a growing collection of lightweight modelling and analysis tools designed to speed up common architectural workflows in Rhino.

## Installation

1. Open **Rhino Package Manager**
2. Enable **Include pre-releases**
3. Search for **Numbat**
4. Install

## Commands

### nbRandomColour

Randomises Rhino layer colours, either per layer or by top-level layer group.

### nbGFA

Calculates Gross Floor Area (GFA) from selected closed polysurfaces by measuring each volume's bottom face.

### nbTextureShuffle

Randomly shuffles texture mapping across selected objects to introduce variation in rendered materials.

### nbPavementPlacer

Arrays a paving module along selected curves, with options for rows, gaps, rotation, scale variation and start-point behaviour.

### nbHandrail

Generates configurable architectural handrails from curves, including rails, posts, panels, sheets, balusters and tabs.

### nbPV

Places photovoltaic panel arrays on selected surfaces, including panel frames, stands and layout options.

### nbStair

Starts the stair generator and lets you choose between straight and spiral stair tools.

### nbStairStraight

Generates straight stairs with configurable construction, landings, switchbacks, stringers and preview/bake workflow.

### nbStairSpiral

Generates spiral stairs with configurable open or closed construction, central column, treads, balusters, handrail, skin and soffit options.

### nbTemplate

Recreates the Numbat template layer structure and places simple reference geometry for each layer.
